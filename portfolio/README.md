## Deploy on Netlify

1. Go to Netlify and choose **Add new site > Import an existing project**.
2. Connect GitHub.
3. Select this repository: `Sindhugd6472/PowerGuardian`.
4. Set the **Base directory** to:

```text
portfolio
```

5. Leave the build command empty.
6. Set the publish directory to:

```text
.
```

7. Deploy.

## Resume

The resume button currently points to:

```text
assets/Sindhu_GD_Resume.pdf
```

Create a folder named `assets` inside `portfolio` and upload the resume PDF with that exact filename, or update the link in `index.html`.

## Customize

Update these values in `index.html`:

- LinkedIn URL
- Resume file path
- Any project wording or dates
- Any additional experience details
